# 来源与公开范围

教师提供并预处理本项目使用的实测 RSSI 指纹表；不是参与者现场自采。该来源依据参与者确认，采集地点、时间、设备、原始 dBm 单位与分发授权没有完整独立记录。

公开归档按用户授权整理历史 MATLAB 实现，但不据此断言算法原创、全部代码独立编写或上游权利已审查完成。沿用仓库许可状态，不增加 MIT/Apache 等宽泛许可。保留代码中已有的说明和文献署名。

## 选择与变更

- `Program` 六个 MATLAB 文件保留为 `matlab/fingerprint`；重复 `代码/Program` 不再次收入。
- `FrLMS&FrRLS` 七个 MATLAB 文件保留为 `matlab/series-benchmark`；MK30 与噪声 MAT 排除。
- `test1/test2/test3` 十四个 MATLAB 文件按方法分目录保留；均为模拟数据，不是真实硬件。
- 所有上述文件均与原件 SHA-256 相同，见 [映射](source-map.json)。源工程未修改。
- 新增 CSV 检查器、MATLAB CSV 入口和微型测试。入口只改数据读取与有效输出长度，仍调用原始算法类；不把修订入口当成历史脚本的完全复现。
- 基于六份旧交接说明重新核对并修订文档。旧版“缺少 genOutsize”的描述已纠正：该函数在 stblrnd.m 内部定义。

## 排除

教师 XLSX、全部 MAT/FIG、ZIP、PPTX、DOC/DOCX/PDF、报告生成脚本、姓名/学号/名单、抽取图片、个人配置、聊天记录和凭据均不发布。历史数字仅在文字审计中引用，不附逐点测量或原图。无已确认的公开数据下载地址。

几何仿真含历史局限：质心无可见站时估计未定义；最小二乘使用 inv，病态几何可能不稳定；TDOA 发收函数只是 disp，占位延迟不表示真实设备；MCL/MCL3D 原默认 1000 次循环本轮未运行。AOA 注释中的辅助编写痕迹按原文保留，不补写个人贡献。

时间序列基准和几何仿真不是 40/16 定位成绩，也不是根目录 70/20 核滤波成绩。
