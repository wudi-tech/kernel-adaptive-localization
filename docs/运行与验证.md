# 运行与验证

## 环境与入口

目标环境为 MATLAB R2022a。根目录核心代码仅使用 MATLAB 功能；Python 只服务可选截图比较，需要 NumPy 和 Pillow，不参与算法训练。Octave 和其他 MATLAB 版本本次未验证。

先把 MATLAB 当前目录切换至仓库根目录。`MAIN_x` 与 `MAIN_y` 各显示一张图；`MAIN_compare_xy` 会组合显示并默认保存本地结果。

```matlab
results = MAIN_compare_xy('Visible','off');
results = MAIN_compare_xy('MakeFigure',false,'SaveOutputs',false);
```

第二种调用仍会执行算法训练，只是关闭绘图和保存。它不属于“仅静态检查”。本次整理没有执行它。

## 检查分层

| 层级 | 命令或入口 | 依赖 | 是否更新模型 |
|---|---|---|---|
| 静态 | `check_static` | MATLAB、源码 | 否 |
| 合成数值检查 | `test_xy_learning_curves` | 源码内的四点微型数据 | 是，少量 |
| 类接口行为 | `test_ppt_class_structure` | 源码内的两点微型数据 | 是，少量 |
| 课程数据回归 | `RunCourseExperiment=true` | 自行授权并放置的三份数据 | 是 |
| 历史基线回归 | 同上及 `BaselineFile` | 自行持有的旧版基线 MAT | 是 |
| 截图核对 | Python 比较脚本 | 自行授权的原版 PPT、已有 CSV | 否 |

公开副本默认不尝试读取教学数据。默认微型测试输出 `COURSE_EXPERIMENT=NOT_RUN`、`BASELINE=NOT_RUN`，不能把它当作定位实验通过。

```matlab
addpath('tests');
check_static;
test_xy_learning_curves;

% 以下仅在你已获得数据使用许可并放置文件后执行：
test_xy_learning_curves('RunCourseExperiment',true);

% 如另有合法持有的基线，可选：
test_xy_learning_curves('RunCourseExperiment',true,'BaselineFile',baselineFile);
```

课程回归检查 70/20 数据维度、固定排列、两次重跑、逐步预测复算 MSE，以及组合图和单坐标图。没有提供基线时会明确输出未做基线比较，不把跳过计为通过。

## 可选截图核对

```text
python tests/compare_reference_image.py --deck <自行授权的原版课件.pptx> --results-dir <本机结果目录>
```

脚本仍针对原版课件特定的嵌入图片和像素坐标；不适用于重排或重新截图后的任意课件。原课件不随仓库提供。本次没有运行该脚本。历史核对只说明栅格位置接近，不证明原始误差数组逐项完全相同。

## 输出与隐私

默认输出目录 `五算法定位曲线输出` 位于本机，不随仓库提交。MAT 内含原始测量、坐标、模型与本机路径；预测 CSV 含测试目标。即使某张图可以查看，也不代表相关数据具备公开分发许可。公开候选稿只保留聚合历史汇总，不包含这些二进制或逐点结果。
