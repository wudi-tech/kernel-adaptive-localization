# 算法与参数

该项目复现教学示例中的具体实现，不宣称覆盖同名算法的所有文献版本。

## 共同的核模型

公共核函数只实现本实验使用的 `gauss`：

```matlab
K = exp(-distanceSquared/(2*sigma^2));
```

输入距离经浮点保护截断为非负。模型用核中心与展开系数生成预测；展开系数不是测试点坐标，也不是强制非负、归一化的注意力权重。

## 更新策略

| 算法 | 当前实现的主要特征 |
|---|---|
| KLMS | 新系数为 `eta*err`，旧核中心保留 |
| FrKLMS | 原始输入字典；更新为 `eta/gamma(3-p)*abs(err)^(2-p)*sign(err)` |
| KRLS | 核岭回归的分块逆矩阵递推，当前未加入遗忘机制 |
| FrKRLS | 分数阶字典变换、非对称核向量与误差权重共同参与递推 |
| KRGMC | 普通高斯输入核；以广义相关熵权重调整误差的递推贡献 |

KRGMC 的误差权重为 `p*abs(err)^(p-2)/(2*ker^2)*exp(-abs(err)^p/(2*ker^2))`。`ker` 是误差尺度；输入核宽度仍是 `sigma`。二者不能混为一个核宽度。

## 参数的作用

`eta` 影响更新步长；`sigma` 影响输入相似度的空间范围；`gam` 影响正则化及数值条件性；FrKLMS 的 `p`、FrKRLS 的 `alpha` 和 KRGMC 的 `p` 含义不同，不能直接横向比较。参数作用耦合，不能承诺某个数值单调改善误差。

当前主函数采用教学材料中的两套参数，未在本次整理中重新搜索。将它们移植到新场景时应重新划分验证集；持续在同一个测试集上看曲线不等于独立的最终泛化评估，也不能证明这些参数具有最优性。

## 数值保护及解释范围

递推含 `1e-12` 级别保护。FrKLMS 的模型返回值改正教学截图中的系数命名笔误；FrKRLS 明确矩阵连乘括号；KRGMC 使用避免零权重除零的等价表达式。这些是实现层面的整理，不构成新算法主张，也不提供任意参数、任意噪声下的稳定性保证。
