# 贡献与来源

## 可以确认的项目工作

依据工程说明、代码和原始项目上下文，本项目完成过教学示例的五算法定位复现，随后按课件结构整理为五个独立类及 X/Y 主函数。可识别的工作包括接口统一、主函数组织、结果导出、数值保护、测试与说明。这些工作有 AI 辅助参与，不能据此声称提出了五种算法。

本次仓库整理保留根目录最终实现，排除旧教学实验和历史副本，补充数据放置说明、公开版测试开关、结果索引及验证范围说明。核心 11 个 MATLAB 文件采用精确文件清单复制，本次不修改其算法或默认参数。

## 不作归属推断的部分

- 课件作者、原始数据采集者及数据所有者尚未完整核实。
- 没有足够证据描述某个团队成员的具体职责或团队贡献比例；不虚构团队名单。
- 本地课件的编辑者元信息不被当作作者、许可或采集者的证明。
- 70 条训练、20 条测试数据由教师课程提供，不是仓库维护者本人采集；采集者与分发许可尚未完整核实，原始数据不上传。
- 旧算法目录是教学/参考来源和历史实验，不另包装成新的原创项目。

## 来源范围

结构依据为课程提供的《室内定位的核自适应滤波方法》系列材料，最终类接口和两个主函数对应完整课件中算法与坐标估计示例。材料未随公开候选稿分发；没有为其补造 DOI、课程网址、作者姓名或开放许可。

旧实验中存在 Weifeng Liu/CNEL（2008）及 xifeng Li（2018）的版权注释，详见根目录第三方声明。它们不证明所有根目录类的归属，也不授予本仓库再许可权。
