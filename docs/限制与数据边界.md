# 限制与数据边界

1. **复现范围有限。** 当前是特定课程示例与参数的实现复现，不是五种算法的统一理论证明或公开基准排行榜。
2. **数据规模写在入口中。** 固定 70 个训练点、20 个测试点和 3 个特征；更换数据需要同步修改断言、图轴和检查。
3. **原始数据未公开。** 未确认分发许可，因此不含表格、排列 MAT、模型 MAT、逐点预测或原始课件。公开副本无法直接复现历史曲线。
4. **泛化边界。** 历史指标只对应课程数据与顺序；不证明跨设备、跨场地或真实部署性能。原始场地、设备、单位与采集协议信息不完整。
5. **计算规模。** 字典默认 `M=Inf`。递推矩阵随样本数增大，更新矩阵的内存开销可达平方量级；当前没有完整的字典稀疏化或大规模性能评估。有限 M 时代码达到容量后停止加入和更新，不是滑动窗口算法。
6. **参数边界。** 只实现 `gauss` 输入核；分数阶参数与误差指数有奇异点，保护项不是任意参数稳定性的证明。构造函数对未知参数字段的处理沿用示例，应自行核对拼写。
7. **图形边界。** 学习曲线显示固定测试集上的每步 MSE，dB 以数值 1 为隐含参考，不可在未核实单位时写成具体物理单位或米级精度。
8. **验证边界。** 2026-09-30 的完整结果属于历史记录；2026-10-25 公开副本通过静态检查与默认微型合成数值测试。课程数据训练、历史基线、图形和截图未在本次重验。
9. **硬件边界。** 本项目没有提供或验证传感器固件、无线采集链路、现场联调与设备部署。本次没有连接设备或重测硬件。
10. **许可边界。** 不附未经确认的宽泛开源许可证；材料来源和衍生权利仍有未确认项；公开归档不代表取得了统一再许可权。
