# 数据格式与自行放置说明

本目录不含原始课程数据、采集记录或训练排列。70 条训练与 20 条测试数据由教师课程提供，不是维护者本人采集。70 条训练与 20 条测试数据由教师课程提供，不是维护者本人采集。数据采集者、场地、采集时间、设备、单位与对外分发许可没有得到完整核实，不能写成仓库维护者自行采集的数据。

如你有权使用对应数据，请在本机准备以下三个文件；不要把它们提交到公开仓库。

| 文件 | 内容 | 当前代码固定大小 |
|---|---|---|
| `11.xlsx` | 训练样本，每行一个位置 | 70×5，纯数值、无表头 |
| `22.xlsx` | 测试样本，每行一个位置 | 20×5，纯数值、无表头 |
| `A.mat` | 名为 `A` 的训练点排列向量 | 70 个整数，恰为 1:70 的完整排列 |

两个表的列顺序均为：

| 列 | 含义 |
|---|---|
| 1 | X 坐标目标 |
| 2 | Y 坐标目标 |
| 3、4、5 | 三维测量特征 |

代码把特征输入和坐标目标同时按 `A` 重排，测试集不重排。每个数值必须有限。课程语境与无线指纹定位有关，但仅凭无表头表格不能补写具体硬件、单位或采集协议；本说明不对此作推断。

如果使用自己的数据，可以自行定义排列，例如 `A=1:70; save('A.mat','A')`，但它不会自动复现原课程曲线。`A.mat` 的原始顺序也没有公开。采用新的数据、单位、顺序或划分后，应重新验证和调参，不能沿用历史误差作为新数据性能。

若样本数或特征数不同，需要同步修改两个主函数的断言、构造矩阵、绘图坐标和测试；本仓库当前不是通用数据加载框架。请勿用不相关的 Mackey–Glass 序列充当真实定位数据。
